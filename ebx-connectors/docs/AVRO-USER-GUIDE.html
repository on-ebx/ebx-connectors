Apache Avro

Bounded Avro Object Container Files for governed file transports.

Evidence: Java 8 provider round-trip verified; live transport acceptance pending
On this page1. Scope2. Limits3. Acceptance

1. Scope

Select avro on an existing file connector. The provider reads Avro object containers and writes a schema derived from flat JSON objects.

2. Safety boundaries

Rows and bytes are bounded. The certified outbound slice supports nullable string, boolean, long, and double fields with the null codec. Nested records, arrays, maps, logical types, schema registry resolution, and streaming ingestion are outside this slice. Unsupported input types fail explicitly.

3. Acceptance

OFFLINE VERIFIED Service discovery, typed round-trip, row ceilings, byte ceilings, invalid input, and complex-type rejection.

LIVE ACCEPTANCE Validate schemas and codec interoperability with the target producer/consumer.
