Google Sheets

Discover workbook metadata, read bounded explicit ranges, and append or update governed rows.

Offline contract verified; live acceptance pending

Configure

Authentication currently supports service-account JSON/file or an encrypted bearer token through the existing GoogleAuth seam. Workload identity is not claimed by this connector. The endpoint is fixed to https://sheets.googleapis.com/v4; localhost is test-only.

Operations

metadata discovers workbook and bounded sheet properties. read requires an explicit A1 range and returns unformatted values. append and update require an explicit range and rows payload.

Formula safety

Writes use RAW by default, so values beginning with formula characters are stored as text. Setting allowFormulas=true switches to USER_ENTERED and must be limited to trusted, reviewed inputs.

Safety and evidence

Requests refuse redirects, cap responses at 1 MiB, restrict endpoints, and report status-only failures. Live service-account exchange, sharing/IAM, pagination, quotas, formula policy, writes, rollback/cleanup, and audit evidence remain pending.
