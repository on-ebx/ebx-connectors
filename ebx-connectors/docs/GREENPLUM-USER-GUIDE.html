1. What the connector does

The Greenplum profile applies product-specific validation and defaults to the connector platform’s bounded JDBC operations. It is PostgreSQL-compatible, but distributed execution, table distribution, and supported SQL features must be verified against the deployed Greenplum release.

Inbound

Read tables or views with prepared, bounded queries.

Outbound

Insert, update, or upsert approved records inside controlled transactions.

Discovery

Inspect schemas, relations, columns, keys, and JDBC types.

Governance

Keep source reads and governed-output writes separately privileged and auditable.

A PostgreSQL-compatible URL does not make every PostgreSQL feature portable. Validate Greenplum distribution keys, update behavior, generated keys, and transaction semantics before enabling writes.

3. Operations

The profile exposes the shared JDBC operations: query, get, insert, update, upsert, execute, catalog, profile, and sample. Reads are bounded; values belong in named parameters rather than concatenated SQL.

4. Build mappings

SELECT company_id, legal_name, country_code, updated_at
FROM governed_source.company
WHERE company_id = :companyId
ORDER BY company_id
LIMIT 1

Map only required columns, use explicit keys, and write governed results to a destination table whose distribution policy is documented. Do not infer uniqueness from segment-local behavior.

5. Safe operating sequence

  1. Capture the existing connector and mapping configuration.
  2. Connect with a read-only identity and verify the expected Greenplum product and database.
  3. Discover one narrowly scoped schema and compare columns, keys, and types with the source contract.
  4. Run a small preview, then a one-record named-parameter query.
  5. Confirm invalid SQL is recoverable and the read-only identity cannot write.
  6. Simulate the mapping and reconcile proposed counts.
  7. For an approved write, use a dedicated destination table and validate distribution, affected rows, rollback, and independent read-back.
  8. Restore the original configuration and rerun diagnostics.
