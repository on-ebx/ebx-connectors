Microsoft Excel (.xlsx)

Bounded OOXML rows for the existing governed file connectors.

Evidence: deterministic round-trip and hostile package limits verified
On this page1. Scope2. Limits3. Acceptance

1. Scope

Select xlsx on SFTP, FTP/FTPS, S3, Azure Blob, or GCS file operations. The first worksheet and first row as headers are supported; outbound rows create one worksheet named Data.

2. Safety boundaries

Input, expanded ZIP content, output, entries, and rows are bounded by the existing max.bytes/max.rows controls. External XML entities, traversal entries, formulas, macros, charts, embedded objects, and legacy binary .xls are not evaluated or supported. Cells are scalar text values.

3. Acceptance

OFFLINE VERIFIED OOXML write/read, row limits, byte limits, ZIP expansion limits, and secure XML parsing.
