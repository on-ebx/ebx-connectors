Apache Cassandra

Discover bounded keyspaces and tables, and execute approved prepared CQL reads and writes.

Offline contract verified; packaged driver provider and live acceptance pending

Configure

Use comma-separated contact points such as node1:9042,node2:9042, TLS, least-privilege credentials, and an explicit local datacenter. The pinned Java 8 dependency is com.datastax.cassandra:cassandra-driver-core:3.11.5.

Operations

keyspaces and tables are bounded metadata operations. read accepts one prepared SELECT, values, page size up to 1,000, and an opaque paging state up to 4,096 characters. write permits one prepared INSERT, UPDATE, or DELETE. DDL, batches assembled from arbitrary CQL, and semicolon-separated statements are refused.

Safety boundary

Cassandra paging state is opaque and query-specific; never edit it or reuse it with another statement. Partition keys must be fully constrained for point operations. Avoid ALLOW FILTERING and unbounded partition scans.

CDC/change feed, schema mutation, LWT/CAS guarantees, counters, logged batches, token-range scans, and driver retry-policy tuning remain outside this tranche.

Acceptance

Offline tests cover validation, prepared-CQL operation guards, paging bounds, dependency metadata, and scope boundaries. Live tests must prove TLS, authentication, datacenter routing, metadata, prepared binding/type conversion, continuation, timeouts, idempotency, and least-privilege denial.
