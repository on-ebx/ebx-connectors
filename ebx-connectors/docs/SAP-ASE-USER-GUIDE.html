SAP ASE

Use SAP jConnect for governed, bounded JDBC discovery, parameterized reads, and controlled transactional writes.

1. Scope and safety

This profile is specifically for SAP Adaptive Server Enterprise through the optional jConnect driver. It is distinct from SAP HANA and from SAP application/OData connectors.

Inbound

Discover approved ASE objects and execute bounded prepared reads.

Outbound

Perform controlled insert, update, and portable upsert transactions.

Dependency

Install a licensed, approved jConnect 16.x driver archive.

Governance

Separate read and write identities, mappings, and evidence.

3. Operations

The profile exposes query, get, insert, update, upsert, execute, catalog, profile, and sample. Named parameters are bound by JDBC. Upsert is portable update-then-insert, not a claim of ASE-native merge parity.

SELECT TOP 1 company_id, legal_name
FROM governed_company
WHERE company_id = :companyId

4. Safe operating sequence

  1. Install and inventory the approved jConnect driver.
  2. Connect with a read-only login and verify ASE and driver metadata.
  3. Discover one approved database/schema and preview a bounded relation.
  4. Run one named-parameter query; prove the read identity cannot write.
  5. Simulate and reconcile the mapping.
  6. For an authorized write, use a fixture table and verify affected rows, rollback, update-then-insert behavior, and read-back.
  7. Restore configuration and retain metrics and cleanup evidence.
