HCL Domino REST API

This Java 8-compatible connector uses HTTPS and the supported REST API Basis surface instead of embedding the proprietary Notes runtime. Configure the server root or /api/v1 URL, a JWT bearer token, and a published database scope.

Operations

lists discovers exposed views and folders without column expansion. query executes one DQL page with explicit count (maximum 1,000), start, timeout, and scan ceilings.

Acceptance boundary: read-only lists and DQL. Documents, attachments, agents, administration, experimental DXL, and writes are excluded. Production requires HTTPS, a least-privilege REST schema/scope, and live Domino REST API acceptance.

Evidence

The contract follows the first-party Basis OpenAPI 1.3.7: /api/v1/lists, /api/v1/query, JWT bearer security, dataSource, and the documented DQL bounds.
