Google Drive metadata

This read-only connector inventories file metadata and configured retention or sensitivity labels without downloading file content. Authenticate with a least-privilege service account or bearer token and explicitly scope every scan to a shared driveId or direct children of a folderId.

Operation

catalog returns bounded catalog assets, stable source IDs, parent IDs, label definitions and assignment status. Configure stable label and field IDs where possible; names are accepted only when they resolve unambiguously.

Acceptance boundary: metadata and published Drive Labels only. Whole-account implicit scans, file-body reads, writes and inferred retention expiry are excluded. Production requires the Drive metadata-readonly and Drive Labels readonly permissions plus live tenant acceptance.

Safe rollout

Start with one dedicated test folder, verify the returned source status fields, then expand the approved scope. A missing, ambiguous or inaccessible label is reported explicitly and is never treated as public data.
