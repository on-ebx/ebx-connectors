MDM REST integration evidence gate

No implementation is claimed without a licensed, versioned API contract and sandbox.

Promotion requires authoritative endpoint and authentication documentation, entity and relationship schemas, pagination, optimistic-concurrency and bulk semantics, rate limits, error envelopes, audit/provenance requirements, and redacted request/response fixtures. A generic REST template may be used only after those controls are recorded; a dedicated connector is justified only when stable product semantics cannot be expressed safely by that template.
