Alation Data Catalog

Configure the Alation instance URL and an API token. The connector sends it only in Alation's documented TOKEN header.

Operations

search calls /integration/v1/search/ with bounded limit and offset. catalog reads one bounded page for datasource, schema, table, or column, with explicit skip.

Acceptance boundary: read-only discovery. Logical-metadata upload, lineage ingestion, and newer entitlement-specific APIs require a separate acceptance tranche.

Evidence

Validated against Alation's first-party Search API, Relational Get APIs, and pagination guidance. Limits are capped locally at 1,000.
