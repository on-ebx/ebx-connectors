1. Scope and naming

The canonical profile covers Actian Avalanche and Actian Vector through the Actian Ingres/Vector JDBC driver. VectorWise is retained only as a legacy compatibility name. It does not imply coverage of unrelated Actian products such as Zen.

Avalanche

Use the JDBC connection string issued for the approved warehouse.

Vector

Connect through the Data Access Server using jdbc:ingres://.

Driver

Install the vendor-supplied iijdbc.jar.

Governance

Keep read and write identities, mappings, and evidence separate.

3. Operations

The profile exposes query, get, insert, update, upsert, execute, catalog, profile, and sample. Upsert means portable update-then-insert, not a claim of product-native merge parity.

SELECT company_id, legal_name
FROM governed_company
WHERE company_id = :companyId
FETCH FIRST 1 ROW ONLY

4. Safe operating sequence

  1. Install and inventory the approved iijdbc.jar.
  2. Connect with a read-only user and verify product, service, database, and driver metadata.
  3. Discover one approved owner/schema and preview a bounded table.
  4. Run one named-parameter query and prove write denial.
  5. Simulate and reconcile mappings.
  6. For an authorized write, verify distribution/partition rules, affected rows, rollback, update-then-insert behavior, and read-back.
  7. Restore configuration and retain metrics and cleanup evidence.
