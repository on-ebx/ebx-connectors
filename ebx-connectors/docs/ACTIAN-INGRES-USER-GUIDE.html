1. Scope and identity

This profile is specifically for Actian Ingres. Although Ingres and Vector share the modern com.ingres.jdbc driver family and URL scheme, this connector does not claim Avalanche, Vector, VectorWise, or Actian Zen acceptance.

Inbound

Discover Ingres objects and execute bounded prepared reads.

Outbound

Perform approved writes inside controlled transactions.

Driver

Install the vendor-supplied iijdbc.jar.

Governance

Separate read and write identities, mappings, and evidence.

Download the driver from Actian’s distribution channel, retain its license and checksum, and certify the exact build against the target Ingres release.

3. Operations

The connector exposes query, get, insert, update, upsert, execute, catalog, profile, and sample. Upsert is portable update-then-insert, not a claim of an Ingres-native merge operation.

SELECT company_id, legal_name
FROM governed_company
WHERE company_id = :companyId
FETCH FIRST 1 ROW ONLY

4. Safe operating sequence

  1. Install and inventory the approved iijdbc.jar.
  2. Connect with a read-only identity and verify Ingres and driver metadata.
  3. Discover one approved owner/schema and preview a bounded table.
  4. Run one named-parameter query and prove write denial.
  5. Simulate and reconcile mappings.
  6. For an authorized write, verify keys, affected rows, rollback, update-then-insert behavior, and independent read-back.
  7. Restore configuration and retain metrics and cleanup evidence.
