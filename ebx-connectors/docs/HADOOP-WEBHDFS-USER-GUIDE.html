Hadoop WebHDFS / HttpFS

Bounded Hadoop-compatible file access through a governed HTTPS gateway.

Offline gateway contract verified; live Hadoop acceptance pending
On this page1. Scope2. Configure3. Operations4. Gates

1. Scope

This connector targets the standard WebHDFS REST surface through an HttpFS or equivalent gateway that terminates data transfer. It does not embed Hadoop clients.

2. Configure

Use an HTTPS endpoint ending in /webhdfs/v1 and a delegated bearer token. The host must pass the platform egress allow-list. URL credentials and clear remote HTTP are rejected.

3. Operations

list returns at most 1,000 statuses. status reads one status. open reads an explicit byte range capped at 10 MiB. create writes at most 10 MiB; overwrite is opt-in. mkdirs creates one directory and delete is always non-recursive. Parent traversal is refused.

4. Explicit gates

Native NameNode/DataNode redirects are refused; use a non-redirecting gateway. Kerberos/SPNEGO login, proxy-user impersonation, recursive deletion, Hive execution, block APIs, and native HDFS are not certified. Live acceptance must verify gateway token policy, TLS, permissions, range semantics, audit, and cleanup.
