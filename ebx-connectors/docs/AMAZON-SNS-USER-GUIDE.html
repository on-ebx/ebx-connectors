Amazon SNS

Publish bounded notifications and discover topics with the shared hardened AWS credential chain.

Evidence state: signed offline fixture verified; live AWS acceptance pending

1. Deliberate scope

This connector publishes one bounded message and discovers one bounded page of topics. It does not create topics, subscribe endpoints, confirm subscriptions, set policies, or administer delivery.

Publishing can fan out to people and systems. Use an approved fixture topic and verify its subscriptions before the first run.

3. Operations

publish sends one message up to 256 KiB with optional subject. topics returns at most 100 topic ARNs and the AWS continuation token. Subscription administration is intentionally absent.

4. Safe run

  1. Use a least-privilege publish/discovery policy.
  2. Verify the fixture topic ARN and every subscription.
  3. Publish a unique non-sensitive fixture.
  4. Confirm message ID and intended delivery evidence.
  5. Retain execution metrics and remove test artifacts where applicable.
