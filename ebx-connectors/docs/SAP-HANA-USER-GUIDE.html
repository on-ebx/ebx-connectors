SAP HANA

Use SAP HANA ngdbc for governed, bounded discovery, parameterized SQL, and controlled transactions.

1. Scope and safety

This profile is specifically for SAP HANA through the optional ngdbc JDBC driver. It is distinct from SAP ASE and SAP application/OData connectors.

Inbound

Discover approved HANA schemas and execute bounded prepared reads.

Outbound

Perform controlled inserts, updates, and portable upserts.

Dependency

Install an approved ngdbc 2.x runtime artifact.

Governance

Use least-privilege technical users and auditable mappings.

3. Operations

The profile exposes query, get, insert, update, upsert, execute, catalog, profile, and sample. Upsert is portable update-then-insert, not a claim of HANA-native UPSERT or MERGE parity.

SELECT COMPANY_ID, LEGAL_NAME
FROM GOVERNED.COMPANY
WHERE COMPANY_ID = :companyId
LIMIT 1

4. Safe operating sequence

  1. Install and inventory the approved ngdbc artifact.
  2. Connect with a read-only user and verify HANA tenant and driver metadata.
  3. Discover one approved schema and preview a bounded object.
  4. Run one parameterized query and prove write denial.
  5. Simulate and reconcile the mapping.
  6. For an authorized write, verify keys, affected rows, rollback, update-then-insert behavior, and independent read-back.
  7. Restore configuration and retain metrics and cleanup evidence.
