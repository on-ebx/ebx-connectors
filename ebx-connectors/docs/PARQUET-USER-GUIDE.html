Apache Parquet

An honest deployment gate, not a claimed runtime capability.

Status: blocked pending an approved Java 8 dependency closure and use case
On this page1. Gate2. Required evidence

1. Why it is gated

The module does not package a Parquet provider. A safe implementation requires a reviewed Java 8-compatible Parquet/Hadoop dependency closure, a selected logical-type and schema contract, and a bounded-input design. Requests fail explicitly; Parquet bytes are never interpreted as text.

2. Evidence before enablement

Approve exact artifacts, licenses, checksums, Java 8 bytecode, CVE posture, maximum compressed and expanded sizes, row-group limits, nested schema behavior, logical types, and fixtures from the target platform. Then install a DocumentCodecProvider claiming parquet.
