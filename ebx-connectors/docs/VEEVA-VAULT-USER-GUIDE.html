Veeva Vault CRM

This dedicated, read-only connector uses the documented Vault REST and VQL APIs. Configure the Vault host as baseUrl, a bearer/session token in the secret field, and optionally apiVersion (default v25.3).

Operations

objects discovers object definitions with a 1–500 result bound. query posts VQL as form data and returns one page; pageSize is capped at 1,000 and pageOffset is explicit.

Acceptance boundary: metadata and bounded reads only. Object writes, bulk jobs, document transfer, and production acceptance against a licensed Vault remain outside this offline contract.

Evidence

Validated against the first-party Veeva Vault API reference: authorization header, /api/{version}/metadata/vobjects, /api/{version}/query, VQL length, and page fields.
