Elasticsearch

Bounded discovery, cursor search, governed document reads, and item-aware bulk indexing.

Evidence state: offline REST fixture verified; live cluster acceptance pending
On this page1. Scope2. Configure3. Operations4. Evidence

1. Safety model

Search is limited to 1000 hits per request and continues only with the previous hit’s sort values as search_after. Positive from is rejected. Bulk indexing is limited to 500 documents and reports every item error.

2. Configure

SettingGuidance
Base URLHTTPS Elasticsearch endpoint; localhost HTTP is fixture-only.
AuthenticationElasticsearch API key, HTTP Basic, or bearer token. Secrets never appear in errors.
EgressThe endpoint must also pass the platform host allow-list.

3. Operations

indices and mapping provide bounded metadata. search uses search_after. get reads one document. bulk sends bounded NDJSON and returns structured item failures. Requests and responses are capped at 5 MiB and redirects are refused.
