MongoDB

Bounded database and collection discovery, governed document CRUD, and deterministic _id keyset paging.

Evidence state: deterministic offline adapter verified; live topology acceptance pending

1. Safety model

The connector uses the Java synchronous driver for bounded metadata and document operations. It does not expose arbitrary database commands, administrative operations, server-side JavaScript, or change streams.

2. Configure

SettingGuidance
Connection URIUse mongodb+srv://…, or mongodb://…?tls=true. Never embed credentials in the URI. Clear transport is accepted only by the isolated loopback fixture.
AuthenticationStore the SCRAM username and password in the connector credential fields. Set authDatabase when it differs from admin.
TLSCertificate and hostname verification remain enabled. tlsInsecure and invalid-hostname overrides are refused.
CompatibilityPackaged MongoDB Java Sync Driver 5.11.x; server 4.2 or later. Verify the approved server topology during live acceptance.

3. Operations

databases and collections discover at most 500 names. find returns at most 500 documents and accepts only a JSON filter object. get, insert, replace, upsert, update, and delete address bounded documents; insertMany accepts at most 100. Operator updates must use keys beginning with $. Documents and filters are capped at 1 MiB by the connector.

4. Paging

Find results are sorted by _id. The returned continuation token is tied to the database and collection and carries the last _id; it cannot be reused against a different namespace. For stable traversal, do not mutate key values during the scan. This is keyset paging, not a retained server cursor.

5. Evidence and acceptance

OFFLINE ADAPTER VERIFIED URI/TLS/auth validation, credential redaction, bounded discovery, CRUD, write ceilings, operator-update rejection, keyset continuation, and token namespace binding are deterministic and need no MongoDB server.

LIVE ACCEPTANCE PENDING Validate CA trust, SCRAM roles, replica-set or sharded failover, BSON type fidelity, read/write concerns, timeout behavior, cleanup, and production metrics on the approved environment.

Not certified: change streams, transactions, arbitrary commands, Atlas-specific authentication, X.509, and deep skip/offset paging.
