Microsoft OneDrive metadata

This read-only Microsoft Graph profile inventories file metadata and source governance labels for an explicitly configured driveId. Use an approved Graph cloud endpoint and either a least-privilege OAuth client or a managed bearer token.

Operation

catalog walks a bounded drive scope, records stable source identities, parent references, retention-label status and—only when explicitly requested—sensitivity-label extraction status. Dry runs disable sensitivity extraction.

Acceptance boundary: metadata inventory only. File-body reads, writes, implicit tenant-wide discovery and silent permission fallback are excluded. Production requires live tenant validation of the selected Graph permissions and governance-label policies.

Safe rollout

Begin with a non-production drive and confirm that inaccessible labels are reported as ACCESS_DENIED, not as absent. Review catalog classifications before enabling the masked preview service.
