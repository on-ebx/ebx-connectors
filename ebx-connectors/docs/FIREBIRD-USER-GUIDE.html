1. Scope and safety

The Firebird profile adds a dedicated URL, driver, descriptor, and bounded configuration contract to the shared JDBC engine. It supports remote Firebird databases through the optional Jaybird driver; embedded and legacy URL forms are deliberately outside this certified profile.

Inbound

Discover relations and run prepared, bounded queries.

Outbound

Insert, update, or upsert approved records in controlled transactions.

Dependency

Install the Java 8-compatible Jaybird 5.x runtime artifact.

Governance

Use separate least-privilege read and write identities with auditable mappings.

3. Operations

The connector exposes query, get, insert, update, upsert, execute, catalog, profile, and sample. Values belong in named parameters. The portable upsert implementation performs update-then-insert; it is not a claim of Firebird UPDATE OR INSERT or MERGE parity.

SELECT COMPANY_ID, LEGAL_NAME, COUNTRY_CODE
FROM GOVERNED_COMPANY
WHERE COMPANY_ID = :companyId
ROWS 1

4. Safe operating sequence

  1. Install the approved Jaybird artifact and record its checksum and version.
  2. Connect first with a read-only Firebird identity.
  3. Verify product and driver metadata, then discover one approved relation.
  4. Run a small preview and one named-parameter query within configured bounds.
  5. Confirm malformed SQL is recoverable and the read-only identity cannot write.
  6. Simulate mappings and reconcile proposed counts.
  7. For an approved write, use a dedicated fixture table; verify affected rows, rollback, update-then-insert behavior, and independent read-back.
  8. Restore the original configuration and retain the execution evidence.
