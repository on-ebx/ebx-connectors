MedPro integration

Blocked pending customer API evidence. Public first-party material confirms partner and API integrations, but does not publish a stable authentication, endpoint, pagination, error, or data-contract specification from which a production connector can be built safely.

Do not guess endpoints in the generic REST connector. To promote this item, obtain the licensed customer API reference, sandbox host, authentication flow, HCP/HCO schemas, paging and rate-limit rules, permitted use, and representative redacted responses. A governed REST template can then be reviewed and promoted to a dedicated type only if its semantics justify it.
