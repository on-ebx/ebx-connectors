Microsoft Purview Data Map

Use the Purview account data-plane endpoint. Authentication is a bearer token or Microsoft Entra client credentials using tenant, client ID, secret, and scope https://purview.azure.net/.default.

Operations

search uses the stable Data Map 2023-09-01 discovery query, caps limit at 1,000, and exposes the continuation token. entity reads one Atlas GUID. types discovers Atlas type definitions.

Acceptance boundary: Data Map reads only. Unified Catalog preview APIs, scans, role administration, and entity mutations are excluded.

Security

Use least-privilege Data Map roles, an allow-listed endpoint, TLS, and a managed secret reference. Error messages expose status only, never response bodies or credentials.
