Azure Table Storage

Discover tables and exchange bounded PartitionKey/RowKey entities through the Azure Table REST API.

Evidence state: loopback REST contract verified; live Azure acceptance pending
On this page1. Configure2. Operations3. Batches4. Safe run5. Evidence

1. Configure

Use the exact HTTPS endpoint https://ACCOUNT.table.core.windows.net with either a narrowly scoped SAS token or an Entra bearer token. Redirects are refused so credentials cannot be forwarded. Responses are capped at 2 MiB and public errors contain status only.

Prefer short-lived, least-privilege credentials. Do not place SAS tokens in URLs, logs, screenshots or evidence.

2. Operations

OperationContract
tablesBounded table discovery with opaque continuation token.
queryAt most 1,000 entities, optional OData filter/select, continuation token.
getExact table, PartitionKey and RowKey.
insertCreate an entity containing valid PartitionKey and RowKey.
update / upsertReplace or insert-or-replace a keyed entity.
deleteDelete a keyed entity, with optional ETag and explicit live-write approval.

Table names and keys are validated; forbidden key characters and CR/LF are rejected.

3. Transactional batches

batch accepts 1–100 entities and one operation: insert, update, upsert or delete. Every entity must have the same PartitionKey because Azure transactions cannot cross a partition. The connector sends one multipart changeset; a failed service response fails the whole connector operation.

4. Safe operating sequence

  1. Grant read-only table permissions and discover a narrow table list.
  2. Query one partition with a small maximum and preserve the continuation token only as opaque state.
  3. Verify PartitionKey/RowKey mapping and ETag behavior.
  4. Simulate writes, then approve one entity and independently read it back.
  5. Exercise a same-partition batch only after single writes pass.
  6. Prove mixed-partition batches, redirects and oversized responses fail safely.
  7. Delete test evidence only with explicit approval and restore the baseline.
